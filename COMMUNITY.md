## Community safety / 社区安全

- Never post API keys, `.env` contents, JWTs, cookies, private keys, provider
  credentials, personal datasets, or production evidence containing secrets.
- 不要发送 API Key、`.env` 内容、JWT、Cookie、私钥、Provider 凭据、个人数据集，
  或包含秘密的生产证据。
- Do not report vulnerabilities in the QQ group, email thread, or a public
  Issue. Follow the private process in [SECURITY.md](SECURITY.md).
- 不要在 QQ 群、普通邮件或公开 Issue 中披露漏洞；请使用
  [SECURITY.md](SECURITY.md) 中的私密报告流程。
- Community help is best-effort. The public preview website and local deployment
  instructions do not constitute a hosted-service SLA or production admission.
- 社区支持为尽力而为；公网预览和本地部署说明不代表托管服务 SLA，也不代表生产准入。

## Before asking for help / 提问前

Please include the operating system, Docker/Compose versions, the command that
failed, and sanitized logs. Remove all secrets and physical database locators.

请提供操作系统、Docker/Compose 版本、失败命令和已脱敏日志，并移除所有秘密与物理
数据库定位信息。
